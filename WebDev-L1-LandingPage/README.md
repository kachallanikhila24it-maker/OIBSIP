
# LearnSphere - Education Landing Page

## About the Project
LearnSphere is a responsive education landing page
designed for an online learning platform.

It helps students explore courses, develop new skills
and learn about educational opportunities.

## Technologies Used
- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries

## Features
- Responsive navigation bar
- Attractive hero section
- Why Choose LearnSphere section
- Popular courses section
- About section
- Contact information and footer
- Smooth scrolling navigation
- Responsive layout for mobile devices

## Project Structure

WebDev-L1-LandingPage/
|
|-- index.html
|-- style.css
|-- README.md

## How to Run
1. Download or clone the project.
2. Open the project folder in VS Code.
3. Open index.html.
4. Right-click and select Open with Live Server.
5. The website will open in your browser.
